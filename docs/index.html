NotifyNexus

Event-Driven Notification Service built with Node.js, RabbitMQ, and PostgreSQL. Designed for reliability with idempotency, retries, DLQ handling, and graceful shutdown.

Core Features

Idempotent processing, exponential backoff retries, dead-letter queue, structured JSON logs, and health checks.

API Endpoint

POST /api/v1/publish-notification-event publishes events for asynchronous processing.
